# ChangeLog for LaunchDock v1.0.1

## New Features

- Added multi-select support for assigning multiple items to a custom category at once.
- Added “Add to Category” submenu for selected items.
- Added hover-based category submenu interaction.
- Added “Remove from Category” action when browsing inside a custom category.

## Improvements

- Selected items now remain highlighted while the context menu is open.
- Category assignment now shows a confirmation toast message.
- The launcher panel remains open after adding items to a category.
- Removing an item from a custom category no longer deletes it from the All category or other categories.
- Directly added folders now display the correct Windows folder icon instead of a drive icon.
- Folder shortcuts now display the icon of their target folder.

## Fixes

- Fixed multi-selection being cleared before category assignment.
- Fixed category removal incorrectly deleting items globally.
- Fixed incorrect folder and folder-shortcut icon extraction.
